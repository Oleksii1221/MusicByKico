2. Description of Service

MusicByKico is a Discord music bot that allows users in a Discord server to play audio from YouTube and YouTube Music in voice channels using slash commands. Features include:

  • Searching and playing tracks by name or URL (/play, /playnext)
  • Queue management (/queue, /remove, /clear, /skip, /back)
  • Playback controls (/pause, /resume, /stop, /volume)
  • Autoplay — automatic recommendations based on listening history (/autoplay)
  • Disconnecting from the voice channel (/disconnect)

The Bot operates exclusively within Discord servers and requires an active Lavalink server to function.
