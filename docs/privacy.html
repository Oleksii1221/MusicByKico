Privacy Policy

MusicByKico — Last updated: April 12, 2026

1. Introduction

This Privacy Policy describes how MusicByKico (the “Bot”), a Discord music bot, handles information when it operates in your Discord server. The Bot is developed and operated by Kico.

By adding MusicByKico to your server or using its commands, you acknowledge this policy.

2. What Data Is Collected

MusicByKico is designed to collect as little data as possible. The following describes what the Bot reads and processes:

  • Discord User IDs — stored temporarily in memory to track who requested a specific track within the current playback session.
  • Discord Guild (Server) IDs — used in memory to maintain a separate playback state (queue, volume, autoplay setting) per server.
  • Discord Text and Voice Channel IDs — used in memory to send playback notifications to the correct channel and to connect to the correct voice channel.
  • Search queries and track metadata — when you use /play or /playnext, the query text is forwarded to YouTube / YouTube Music via a self-hosted Lavalink server to resolve the audio track. The query and resulting track title / author / URL are held in memory during the session only.
  • Playback history (in-memory) — up to 25 recently played tracks per server are stored in memory to power the autoplay recommendation feature. This data is never written to disk and is cleared when the Bot leaves the voice channel or the container restarts.

3. What Data Is NOT Collected

  • Message content — the message_content Discord intent is explicitly disabled in the source code. The Bot never reads chat messages.
  • Usernames, display names, avatars, or any profile data.
  • Any data written to a database, file, or persistent storage of any kind.
  • Payment information.
  • Any data from users who have not directly interacted with the Bot.

4. How Data Is Used

  • To play music requested by users in the voice channel.
  • To maintain the per-server queue, volume, and autoplay state during an active session.
  • To generate autoplay recommendations based on recently played tracks (in memory only).
  • To send playback status messages to the bound text channel.

5. Legal / Operational Basis

The Bot operates on the basis of legitimate interest: all data processing is strictly necessary for the Bot to perform the service you invited it to provide. No data is processed for advertising, profiling, or any purpose beyond active music playback.

6. Data Storage and Retention

All data processed by MusicByKico is held exclusively in application memory (RAM) for the duration of an active playback session. No data is persisted to any database, file system, or third-party storage service.

All in-memory data is automatically discarded when:

  • The Bot disconnects from the voice channel (/disconnect, /stop, or inactivity timeout).
  • The Bot container restarts.

7. Third-Party Services

  • Discord — the Bot operates via the Discord API. Discord’s Privacy Policy applies to all data that passes through their platform.
  • YouTube / YouTube Music — search queries and track URLs are resolved via Lavalink using YouTube’s public data. Google’s Privacy Policy applies to requests made to YouTube.
  • Lavalink — a self-hosted audio streaming server operated by the Developer. No user data leaves the Developer’s infrastructure through Lavalink to any third party beyond YouTube.
  • Telegram Bot API Operator-only — if configured, the Bot sends internal error alerts (track exceptions, node outages) to a private Telegram chat controlled by the Developer. These alerts contain only technical error details (track title, error code) and are never shared with users.

8. Data Sharing

MusicByKico does not sell, rent, trade, or share any user data with any third party, advertiser, or analytics provider. The only external data flow is search queries forwarded to YouTube via Lavalink for the purpose of audio resolution.

9. Security

The Bot runs in a containerized Docker environment. No user data is stored persistently, which significantly limits the risk of data exposure. The Lavalink audio server is password-protected and not publicly accessible. All in-memory session data is cleared automatically at session end.

10. Children’s Privacy

MusicByKico does not knowingly collect any information from children. The Bot operates within Discord, which requires users to be at least 13 years old per Discord’s Terms of Service.

11. Your Rights

Because MusicByKico stores no persistent personal data, there is nothing to access, export, or delete after a session ends. If you have concerns about data processed during an active session, you may ask a server administrator to remove the Bot from the server, which terminates all processing immediately.

If you believe any data about you has been improperly handled, contact us at the address below.

12. Changes to This Policy

This policy may be updated if the Bot’s functionality changes in ways that affect data handling. The “Last updated” date at the top reflects the most recent revision.
